# Техническое задание
## Онлайн-школа (курсовая работа)

### 1. Назначение системы
Веб-приложение для управления онлайн-курсами: каталог курсов, запись студентов, управление преподавателями и администрирование.

### 2. Роли пользователей

#### 2.1 Администратор (`is_staff` + роль «Администратор»)
| № | Возможность |
|---|-------------|
| 1 | Полный CRUD категорий и курсов |
| 2 | Управление записями студентов (создание, изменение статуса, удаление) |
| 3 | Просмотр журнала действий (`ActionLog`) и экспорт данных |
| 4 | Управление ролями пользователей через админ-панель |

#### 2.2 Преподаватель (роль «Преподаватель»)
| № | Возможность |
|---|-------------|
| 1 | Создание и редактирование **своих** курсов |
| 2 | Просмотр списка записей на свои курсы |
| 3 | Просмотр истории изменений курса (API `/api/courses/{id}/history/`) |
| 4 | Фильтрация и поиск курсов в API |

#### 2.3 Студент (роль «Студент»)
| № | Возможность |
|---|-------------|
| 1 | Просмотр опубликованных курсов в каталоге |
| 2 | Запись на курс (веб-форма и API `POST /api/courses/{id}/enroll/`) |
| 3 | Отмена своей записи / завершение обучения |
| 4 | Просмотр своих записей (`/enrollments/`, API `?mine=1`) |

### 3. Бизнес-логика и валидация

#### 3.1 Категория
- Название без цифр и спецсимволов (только буквы, пробелы, дефис).
- Уникальность названия (без учёта регистра).
- Запрет запрещённых слов («пакость», «ругательство», «спам»).

#### 3.2 Курс
- Название уникально в рамках категории.
- Цена > 0.
- Дата старта ≤ дата окончания.
- Преподаватель — только пользователь с ролью «Преподаватель».
- Неопубликованные курсы видны только администраторам и преподавателю курса.

#### 3.3 Запись на курс
- Один студент — одна запись на курс (уникальность `user + course`).
- Запись только на **опубликованный** курс.
- Нельзя записаться на курс, дата окончания которого уже прошла.
- Статусы: `active` → `finished` / `canceled`; отменённую запись нельзя активировать без прав администратора.

### 4. Технические требования (курсовая)

| Пункт | Реализация |
|-------|------------|
| Валидация БЛ | `models.clean()`, формы, сериализаторы |
| `select_related` | Списки курсов, записей, детальные страницы |
| Сериализаторы | `SerializerMethodField`, контекст `request` |
| Аннотации | `Count('enrollment')`, `Avg('price')` по категориям |
| FilterSet | Фильтрация по цене, категории, преподавателю |
| Postman | `postman/School_API.postman_collection.json` |
| Sentry | Интеграция через `SENTRY_DSN` |
| Тесты | ≥ 10 тестов в `school/tests/` |
| Докстринги + типизация | Все публичные функции и методы |
| Django Silk | Профилирование запросов (`/silk/`) |
| Celery | Напоминания о старте курсов, очистка логов |
| Mailhog | Тестирование e-mail в Docker |
| Деплой | Gunicorn + docker-compose production |
| OAuth2 | Google / VK через `social-auth-app-django` |

### 5. API-эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET/POST | `/api/courses/` | Список / создание курсов |
| GET/PUT/PATCH/DELETE | `/api/courses/{id}/` | Детали курса |
| POST | `/api/courses/{id}/enroll/` | Запись на курс |
| GET | `/api/courses/{id}/history/` | История изменений |
| GET | `/api/courses/upcoming/` | Курсы, стартующие в ближайшие 7 дней |
| GET | `/api/enrollments/` | Список записей |
| GET | `/api/enrollments/?mine=1` | Свои записи |

### 6. Стек технологий
Django 5.2, DRF, django-filter, simple-history, Celery, Redis, Sentry, Silk, Mailhog, Gunicorn, Docker.
